# Security

Report security issues privately to the repository maintainer or installation operator. If GitHub private vulnerability reporting is enabled, use it from the repository’s Security tab. Include the affected version, impacted endpoints or records, and steps to verify the issue with test data. Keep credentials, invitation tokens, and customer or business information out of public reports.

Deployment operators are responsible for HTTPS, secrets, database and upload backups, dependency updates, and access to production logs. See [deployment instructions](README.md#deployment).
